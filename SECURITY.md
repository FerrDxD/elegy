# Security Policy

## Supported Versions

Elegy saat ini mendukung pembaruan keamanan untuk versi utama (main branch). Mengingat proyek ini masih dalam tahap awal pengembangan, kami menyarankan Anda untuk selalu mengambil (pull) kode terbaru dari repositori utama.

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Keamanan dari data dan tulisan pengguna di **Elegy** adalah prioritas mutlak kami. 

Jika Anda menemukan kerentanan atau celah keamanan dalam proyek ini, **tolong jangan** melaporkannya dengan membuat _public issue_ di GitHub.

Sebagai gantinya, silakan laporkan masalah tersebut langsung kepada kami melalui email ke **maulanaferdi0678@gmail.com**

Mohon sertakan informasi berikut saat membuat laporan:
- Deskripsi kerentanan (vulnerability).
- Langkah-langkah untuk mereproduksi celah tersebut.
- Potensi dampak jika celah tersebut dieksploitasi.
- (Opsional) Saran solusi jika Anda memilikinya.

Kami akan berusaha memberikan respons awal atas laporan Anda dalam waktu maksimal 48 jam dan akan terus memberi tahu Anda tentang kemajuan penanganan isu tersebut.

Terima kasih telah membantu menjaga Elegy tetap menjadi ruang yang aman untuk semua orang!
